🌐 业务全景
五类用户（政府便民/小微律所/集团法务/个人/运营）接入同一平台，由七大可复用子图智能体支撑，达成法律服务标准化、普惠化、降本三大业务目标。
SECTION 02
🧩 七大能力矩阵
通用检索 / 预处理 / 合同合规（编排外壳）/ 法律问答 / 文书生成 / 普法小红书 / 风险审查。共享检索与预处理底座，业务规则全在 YAML，法务可无代码迭代。

🚀 部署交付
面向政府便民、小微律所、集团法务、个人用户提供私有化/演示双模式交付，适配不同合规与预算约束。

🗂️ 八大任务 × 智能体协作映射

平台按代码 task_type 枚举承载八大任务（合同审核 / 合规审查 / 法律检索 / 案例检索 / 法律问答 / 文书生成 / 小红书 / 通用兜底）。每个任务由若干"可复用子图智能体"协作完成，仅列出代码真实存在的智能体：合同审核/合规审查经 contract_compliance 编排外壳调度预处理+检索+风险审查三智能体；法律问答/文书生成内部嵌套调用通用检索；小红书独立运行。

SECTION 03

🔄 端到端数据流（含人机协同断点）

一条用户请求从入口到交付的完整旅程：两级意图路由分发到五条业务路径，各路径产出结构化交付物；高风险文书、付费法规、企业资信三类场景由 interrupt() 真中断，等待律师/用户确认后 Command(resume=) 续跑。所有节点写入 AgentState，全链路可复盘追溯。

💡 点击节点查看每环节的输入/输出与人工断点设计。
SECTION 04

⚖️ 合规人机协同边界：AI 辅助 / 律师终审签章

依据《律师法》确立权责边界：低风险/中风险由 AI 自动处理并出具可溯源报告；高风险文书强制人工签章中断、付费法规库与企业资信核查须经人工确认，从机制上规避 AI 执业法律风险与资损。合规审查对合同审核拥有"一票否决权"。

SECTION 05

🚀 部署与交付模式

面向不同客群提供差异化部署：政府便民（公有云/政务云）、小微律所（SaaS/轻私有化）、集团法务（全私有化 + 定制规则）、个人用户（演示/轻量）。前端演示模式（HAS_BACKEND 探测）可在无后端时纯前端展示。
