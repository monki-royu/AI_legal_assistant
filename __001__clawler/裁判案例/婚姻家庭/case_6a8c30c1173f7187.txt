# 案件标题: 王某诉李某婚内抚养费纠纷案
# 案号: (2024)渝0106民初4567号
# 案由: 婚姻家庭
# 审理法院: 重庆市北碚区人民法院
# 裁判日期: 2024-01-18
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告王某与被告李某系夫妻，育有一子。李某自2022年起因工作调动长期在外地，每月仅寄回少量生活费，王某独自抚养孩子压力巨大，且李某拒绝增加抚养费。王某诉请李某按当地生活标准支付婚内抚养费。李某辩称自己收入有限，且家庭财产属于共同财产，无需另行支付。

【判决结果】
法院认为，父母对子女的抚养义务不因婚姻状态而免除。李某长期在外未充分履行抚养责任，王某有权要求李某支付抚养费。判决李某自2024年2月起每月向王某支付抚养费2500元，直至子女独立。
