# 案件标题: 北京某科技有限公司与上海某信息技术有限公司买卖合同纠纷案
# 案号: (2024)京0105民初12345号
# 案由: 合同纠纷
# 审理法院: 北京市朝阳区人民法院
# 裁判日期: 2024-06-15
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告北京某科技有限公司（以下简称“科技公司”）与被告上海某信息技术有限公司（以下简称“信息公司”）于2022年3月签订《设备采购合同》，约定科技公司向信息公司采购一批服务器设备，总价款150万元，交货期为2022年5月30日前。科技公司按约支付了全部货款，但信息公司仅交付部分设备，剩余价值60万元的设备经多次催告仍未交付。科技公司遂诉至法院，请求解除合同、返还已支付货款并赔偿损失。信息公司辩称因上游供应商违约导致无法按时交货，属于不可抗力，要求免责。法院查明，信息公司未能提供充分证据证明不可抗力的存在，且其在签约时已预见到供应链风险。

【判决结果】
法院认为，信息公司未按约交付全部设备，构成根本违约，科技公司有权解除合同。信息公司关于不可抗力的抗辩不成立，因其未能证明不可抗力事件直接导致合同无法履行。判决解除双方签订的《设备采购合同》，信息公司于判决生效之日起十日内返还科技公司剩余货款60万元，并赔偿逾期交货造成的损失5万元。案件受理费由信息公司负担。
