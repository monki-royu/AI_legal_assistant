# 案件标题: 赵某与北京某教育公司年终奖发放争议案
# 案号: (2025)京0112民初3344号
# 案由: 劳动争议
# 审理法院: 北京市通州区人民法院
# 裁判日期: 2025-03-20
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告赵某于2022年1月入职被告北京某教育公司，担任课程顾问，劳动合同约定年终奖根据公司业绩及个人绩效发放。2024年1月，公司以赵某2023年度考核不合格为由拒绝发放年终奖。赵某主张考核结果不公，且公司未提供考核标准。仲裁裁决驳回请求，赵某起诉。法院审查发现，公司制定的考核制度未依法经民主程序且未公示，考核结果缺乏客观依据。

【判决结果】
法院判决被告支付原告2023年度年终奖24000元（参照往年发放标准及同岗位水平）。公司考核制度因程序瑕疵不能作为依据。案件受理费由被告负担。
