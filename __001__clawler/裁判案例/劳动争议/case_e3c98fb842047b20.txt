# 案件标题: 刘某与深圳某科技公司竞业限制补偿金纠纷案
# 案号: (2024)粤0305民初44556号
# 案由: 劳动争议
# 审理法院: 深圳市南山区人民法院
# 裁判日期: 2024-09-28
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告刘某于2020年6月入职被告深圳某科技公司，担任高级算法工程师，双方签订竞业限制协议，约定离职后两年内不得从事竞争业务，公司按月支付补偿金。2023年7月刘某离职，公司以刘某未履行报告义务为由拒绝支付补偿金。刘某申请仲裁要求支付竞业限制补偿金。法院查明，竞业限制协议未明确约定报告义务，且刘某未实际入职竞争企业，公司应履行补偿义务。

【判决结果】
法院判决被告支付原告竞业限制补偿金共计144000元（按离职前十二个月平均工资的30%计算，共24个月）。被告提出的反请求因证据不足不予支持。
