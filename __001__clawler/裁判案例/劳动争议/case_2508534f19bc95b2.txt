# 案件标题: 张某与上海某贸易公司违法解除劳动合同赔偿金纠纷案
# 案号: (2023)沪0101民初23456号
# 案由: 劳动争议
# 审理法院: 上海市黄浦区人民法院
# 裁判日期: 2023-11-20
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告张某于2018年7月入职被告上海某贸易公司，担任销售经理，月工资20000元。2023年3月，公司以张某严重违反规章制度为由单方解除劳动合同，理由是张某在报销中虚增差旅费。张某主张报销均经主管审批，不存在违规，且公司从未告知该规章制度。张某申请仲裁后起诉，要求支付违法解除劳动合同赔偿金。法院查明，公司未能提供规章制度已向张某公示或送达的证据，且报销审批流程显示主管已确认，故解除行为缺乏依据。

【判决结果】
法院认定被告解除劳动合同违法，判决支付原告张某违法解除劳动合同赔偿金200000元（按工作年限4.5年，双倍计算）。案件受理费由被告承担。
