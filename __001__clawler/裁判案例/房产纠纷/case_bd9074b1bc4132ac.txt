# 案件标题: 某银行与周某金融借款合同纠纷（房屋抵押）案
# 案号: (2022)浙0106民初54321号
# 案由: 房产纠纷
# 审理法院: 浙江省杭州市西湖区人民法院
# 裁判日期: 2022-08-25
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告某银行与被告周某签订个人购房借款合同，周某向银行贷款200万元用于购买西湖区某房屋，并以该房屋作为抵押，办理了抵押登记。后周某因失业连续6个月未还贷款本息，银行宣布贷款提前到期并诉请周某偿还全部剩余贷款本息共计185万元，并请求对抵押房屋行使优先受偿权。周某辩称经济困难请求减免利息，但未获支持。法院查明借款合同、抵押登记及违约事实清楚，银行诉求合法。

【判决结果】
一、被告周某于本判决生效之日起十日内偿还原告某银行贷款本金及利息、罚息共计185万元；二、原告某银行对被告周某名下位于杭州市西湖区某房屋的折价、拍卖、变卖所得价款享有优先受偿权；三、驳回原告其他诉讼请求。案件受理费由被告负担。
