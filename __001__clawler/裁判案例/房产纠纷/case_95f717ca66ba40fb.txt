# 案件标题: 赵甲、赵乙与赵丙房屋所有权确认纠纷案
# 案号: (2024)粤0104民初23456号
# 案由: 房产纠纷
# 审理法院: 广东省广州市越秀区人民法院
# 裁判日期: 2024-03-10
# 数据来源: LLM生成(结构真实)

【案情摘要】
原告赵甲、赵乙与被告赵丙系兄妹关系。父母去世后遗留位于越秀区的一套房屋，未立遗嘱。三兄妹曾口头约定房屋由赵丙居住，但产权归三人共有。后赵丙擅自将房屋登记至自己一人名下，并准备出售。赵甲、赵乙诉至法院，请求确认房屋为三人共同所有，并判令赵丙协助办理共有产权登记。赵丙辩称父母生前已将该房屋赠与给自己，但未能提供赠与合同或证据。法院经调查，房屋原登记在父亲名下，父亲去世后未办理继承登记，赵丙私自通过虚假材料变更登记，行为无效。

【判决结果】
一、确认位于广州市越秀区某路某号的房屋为赵甲、赵乙、赵丙共同所有，各占三分之一份额；二、被告赵丙于本判决生效之日起三十日内协助原告赵甲、赵乙办理房屋共有产权登记手续；三、驳回原告其他诉讼请求。案件受理费由被告负担。
