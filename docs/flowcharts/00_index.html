16节点完整链路：文档提取 → 合同分类 → 条款切分 → 数值抽取 → 合同审核AI → 合规审查 → 数值校验 → 🔄5阶段检索(N09a-e) → 甲乙方识别 → 🏢企查查资信查询 → 四路风险聚合(条款+合规+数值+资信) → 最终交付。

16节点 · 企查查MCP · 四路风险聚合
AGENT 02 · 检索核心

🔍 检索智能体

横向按需挂载 + 纵向逐级降级双层策略：
① 横向全局规划：根据合同类型在基础层4路通用检索并行同时，动态挂载行业增强层特定数据源（如建设工程→住建部标准）。
② 纵向逐级降级：L1 FAISS向量+知识图谱高精度匹配 → 不足则降级 L2 本地法规txt关键词兜底 → 极端情况 L3 LLM伪检索防死循环。
最终 RRF 融合排序 → 结果输出。被合同审核/合规审查/法律检索三条链路🔄复用。

横向4路+行业挂载 · 纵向3级降级 · RRF融合
AGENT 03 · 合规审查

🛡️ 合规审查智能体

精简链路：文档提取 → 合规审查(刚性不降级) → 数值校验 → 🔄5阶段检索 → 甲乙方识别 → 🏢企查查资信查询 → 四路风险聚合 → 最终交付。合规结论刚性不被商业条款审核降级。

精简链路 · 合规刚性 · 企查查MCP
AGENT 04 · 法律问答

💬 法律问答智能体

Text-to-Cypher链路：用户提问 → 实体抽取 → Neo4j匹配 → Cypher生成/校验(≤3次重试环) / 执行 → 答案生成。Neo4j/Cypher超限失败降级至LLM直答，保证可用性。

知识图谱 · Cypher重试 · 降级兜底
AGENT 05 · 小红书发布

📱 小红书发布智能体

入口前置(Intent Filter)：START后第一节点即小红书识别 → 文案生成 → 图片生成 → 质量检查(不通过→直接结束) → 自动发布 → Markdown报告。独立链路，不经过主意图路由。

前置过滤 · 文案图片 · 自动发布
