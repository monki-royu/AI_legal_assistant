⚡ 重要设计说明：合同审核 与 合规审查 的关系

合同审核 = 商业律师角色（立场化，站在客户一方挑商业风险，可谈判）
合规审查 = 合规律师角色（客观中立，检查法律强制性规定，刚性不可谈判）

合规有一票否决权：合规结果与合同审核冲突时，以合规为准。
二者从检索输出后分支并行执行，通过 冲突消解节点 合并，确保合规优先级。
