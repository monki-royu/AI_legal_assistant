AGENT 04 · 法律问答

💬 法律问答智能体

基于法律知识图谱的法律问答链路：用户提问 → 实体抽取 → Neo4j 匹配 → Cypher 生成/校验/执行 → 答案生成。Neo4j 失败时降级至 LLM 直答，保证可用性。

❓ N01

用户提问

用户通过自然语言提出法律问题，例如「盗窃罪的最高刑期是多少？」「劳动合同试用期最长多久？」。

入口节点 · 自然语言 query
🧭 N02

意图路由 (法律问答)

LLM 识别用户意图为「法律问答」，路由进入法律问答智能体分支（legal_qa_intent）。

🏷️ N03

实体抽取 (extract_entity)

从用户问题中抽取法律实体：罪名 / 法条 / 主体 / 行为 / 数额 / 期限等，结构化为图谱查询输入。

🔗 N04

Neo4j 匹配 (match_entity)

将抽取的实体与 Neo4j 法律知识图谱节点进行匹配，定位相关法条、罪名、量刑情节等子图。

知识图谱匹配 · 失败则降级
📝 N05

Cypher 生成 (generate_cypher)

LLM 基于匹配到的实体与图谱 schema 生成 Cypher 查询语句，用于精确检索法律知识图谱。

✅ N06

Cypher 校验 (check_cypher)

对生成的 Cypher 进行语法 + 安全性校验，防止注入风险与无效查询。校验失败则重新生成。

确定性门禁 · 安全校验
▶️ N07

Cypher 执行 (run_cypher)

在 Neo4j 中执行校验通过的 Cypher，返回法条、量刑、关系等结构化图谱数据。

🛟 降级路径：Neo4j 匹配/执行失败 → 跳转 LLM 直答 (llm_direct_out) 节点 → LLM 结合 RAG 检索结果直接生成答案，保证用户始终得到回复。
💡 N08

答案生成 (neo4j_answer_generate)

LLM 基于图谱结构化数据 + 用户问题生成自然语言答案，附带法条引用、量刑区间、相关案例。

📦 N09

输出交付

结构化输出：答案正文 + 引用法条 + 图谱路径 + 置信度。支持 source_tag 审计追溯。
