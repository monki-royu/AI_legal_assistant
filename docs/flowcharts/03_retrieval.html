AGENT 02 · 检索核心

🔍 检索智能体

9 阶段检索链路：上游调用 → 意图分解 → 并行调度（4 路 + 行业层 + 条款层）→ RRF 融合 → 冲突消解 → 质量网关 → 重试环 → 结果聚合 → 结构化输出。可被多个上游 Agent 复用。

📥 N01

上游调用

接收上游 Agent（合同审核 / 合规审查 / 法律问答）的检索请求，携带 query、context、立场等参数。

复用入口 · 不重复计算
🧩 N02

意图分解 (N1)

将原始 query 分解为多个子意图（向量意图 / 关键词意图 / 实体意图 / 法规意图），为并行调度做准备。

⚡ N03

并行调度 (N3 · 4 路并行)

Send API 并行调度基础层 4 路 + 行业增强层 N 路 + 条款级动态触发。4 大检索策略同时执行。

↓ 基础层 4 路并行 ↓
VECTOR 向量检索Milvus + bge-m3 语义召回
BM25 全文检索关键词倒排匹配
GRAPH 知识图谱Neo4j 实体关系检索
LAW 法规库结构化法规条文检索
🔀 N04

RRF 融合 (Reciprocal Rank Fusion)

倒数排名融合算法合并多路结果，消除各路打分尺度差异，生成统一排序的候选集。

⚖️ N05

冲突消解

检测多源结果中的矛盾条款（如不同效力层级的法规冲突），按效力优先级 + 时效性消解。

确定性门禁 · Python 代码
🚦 N06

质量网关

计算结果质量分（相关性 + 覆盖率 + 时效性）。质量分 ≥ 0.85 通过；< 0.85 进入重试环。

🔄 重试环 (N07)：质量分 < 0.85 → 回到 N02 意图分解重新生成子查询 → 最多重试 3 次 → 3 次失败升级人工处理。
🧺 N08

结果聚合

聚合通过质量网关的结果，去重、排序、附加 source_tag（来源标记），生成结构化候选集。

📦 N09

结构化输出

返回结构化检索结果给上游 Agent，包含条文内容、来源、bbox、置信度等字段，支持审计追溯。
