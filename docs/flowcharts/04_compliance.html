AGENT 03 · 合规审查

🛡️ 合规审查智能体

基础筛查必做 + 深度审查按需触发 → LLM 动态合规校验 → 双视角协同（contract_ref / compliance_ref）→ 6 维比对矩阵 → 高风险人工签章。完整合规闭环。

🔬 N01

基础筛查

对合同进行必做的合规性基础筛查：主体资格、经营范围、签章要件、法定形式等基础维度。

必做节点 · 全量执行
🎯 N02

深度审查触发

根据基础筛查结果 + 合同类型 + 风险信号，判断是否触发深度审查。高风险/敏感领域自动触发。

条件分支 · 按需触发
🤖 N03

LLM 动态合规校验

LLM 基于法规库 + 行业规范动态生成校验规则，对条款逐条合规性判定，输出违规点 + 引用依据。

👁️‍🗨️ N04

双视角协同

两个视角并行审查：contract_ref（合同条款视角）+ compliance_ref（合规规范视角），交叉验证避免遗漏。

↓ 双视角并行 ↓
📄 contract_ref从合同条款出发，逐条比对合规要求
📐 compliance_ref从合规规范出发，反查合同是否覆盖
📊 N05

6 维比对矩阵

6 维度比对：合法性 / 合规性 / 完整性 / 一致性 / 风险性 / 可执行性。生成比对矩阵 + 违规定级。

✅ N06

合规结论

生成合规结论：通过 / 有条件通过 / 不通过。高风险项触发人工签章流程，输出合规审查报告。

高风险 → 人工签章
🔬 基础 + 深度基础筛查必做，深度审查按需触发
🤖 动态校验LLM 动态生成校验规则，适配多场景
👁️ 双视角contract_ref + compliance_ref 交叉验证
📊 6 维矩阵合法/合规/完整/一致/风险/可执行
