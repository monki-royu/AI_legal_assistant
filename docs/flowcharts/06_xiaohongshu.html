AGENT 05 · 小红书发布

📱 小红书发布智能体

法律科普内容自动生产与发布链路：用户输入主题 → 发布意图确认 → 文案生成 → 图片生成 → 质量检查 → 自动发布 → Markdown 报告。质量不通过自动重试生成。

💡 N01

用户输入主题

用户输入法律科普主题，例如「租房合同避坑指南」「劳动者维权须知」「个人信息保护常识」。

入口节点 · topic 输入
🧭 N02

意图路由 (小红书)

LLM 识别用户意图为「小红书发布」，路由进入小红书发布智能体分支（xiaohongshu_publish_intent）。

🔐 N03

发布意图确认

二次确认用户发布意图，避免误触自动发布。确认后才进入文案与图片生成流程。

人机交互 · 防误触
✍️ N04

文案生成 (text_generate)

LLM 生成小红书风格文案：标题党 + emoji + 标签 + 法律知识点 + 行动建议，符合平台调性。

🎨 N05

图片生成 (image_generate)

基于文案生成配图（封面 + 内页图），适配小红书竖版比例，含法律主题视觉元素。

🔍 N06

质量检查 (check_text_image)

检查文案合规性（无违规词/法律准确性）+ 图片质量（清晰度/相关性）。通过则发布，不通过则重试。

质量门禁 · 不通过则重试
🔄 重试路径：质量检查不通过 → 回到 N04 文案生成重新生成文案 + 图片 → 最多重试 3 次 → 3 次失败升级人工处理。
🚀 N07

自动发布 (auto_publish)

通过质量检查后，使用 cookies 自动登录小红书并发布图文笔记，含标题、正文、配图、标签。

📋 N08

Markdown 报告 (generate_markdown)

生成发布报告（Markdown）：主题、文案、图片路径、发布链接、时间戳，便于审计与复盘。

📦 N09

输出交付

输出最终结果：发布链接 + 文案存档 + 图片存档 + Markdown 报告。全程可追溯。

🎨 图片生成竖版配图 · 法律主题视觉
🔍 质量门禁合规性 + 准确性 + 图片质量
