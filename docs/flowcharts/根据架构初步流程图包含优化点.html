📐 7条数值校验规则速查

HIGHNUM001 单价×数量=总价 (±0.1%)
HIGHNUM002 含税=不含税×(1+税率)
HIGHNUM004 违约金比例≤30%(§585)
HIGHNUM005 固定违约金/总价≤30%
MEDNUM006 各期付款比例和=100%
HIGHNUM007 定金/保证金≤20%(§586)
MEDNUM009 逾期利率≤LPR×4(≈13.8%)
LOWNUM010 保修期≤36月(可配)

🔑 关键设计决策

为什么不全用混合检索?
→ 资信是结构化数据，向量化无意义
→ 法规编号精确匹配比语义更准
→ 不同源时效性要求不同

为什么不全按类型分叉?
→ 一份合同横跨多个领域
→ SaaS合同藏了数据跨境条款
→ 关键词扫描弥补类型分类不足
