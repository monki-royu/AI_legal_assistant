文档解析器（MinerU）的输出
当用户上传合同/文档时，文档解析节点处理上传的文件：

4.1 主流方式（MinerU 多模态解析）
# doc_structured 字段的结构
state["doc_structured"] = {
    "metadata": {
        "file_name": "买卖合同.docx",
        "file_type": "docx",
        "total_pages": 5,
    },
    "pages": [
        {
            "page_idx": 0,
            "blocks": [
                {
                    "type": "text",                    # 文本块
                    "content": "甲方：XX科技有限公司",
                    "bbox": [0.1, 0.05, 0.9, 0.12],   # 坐标[x1,y1,x2,y2]
                },
                {
                    "type": "table",                   # 表格块
                    "content": "| 项目 | 金额 |\\n|------|------|\\n| 总价 | 500万 |",
                    "bbox": [0.1, 0.2, 0.9, 0.5],
                },
                {
                    "type": "image",                   # 图片块（印章/签名）
                    "content": "/tmp/mineru_extracted/fig_001.png",
                    "bbox": [0.7, 0.8, 0.95, 0.95],
                    "image_caption": "合同盖章页",
                }
            ]
        }
    ]
}


4.2 降级方式（纯文本提取）
# MinerU 不可用时
