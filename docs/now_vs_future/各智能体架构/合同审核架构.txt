合同审核 = 保护客户商业利益（立场化、可谈判、商业导向）
用户上传合同 → MinerU 文档解析
                    ↓
              doc_clauses（条款列表）
                    ↓
         ┌─── 合同分类节点 ───┐
         │  识别合同类型       │
         │  (买卖/租赁/劳动等) │
         └────────┬───────────┘
                  ↓ contract_type="买卖合同"
         ┌─── 条款切分节点 ───┐
         │  按"第X条"切分条款  │
         └────────┬───────────┘
                  ↓
         ┌─── 数值抽取节点 ───┐          ┌─── 检索智能体 ───┐
         │ 用正则+LLM提取:    │          │ 根据 contract_type│
         │  单价/数量/总价    │  ←────── │ + retrieval_query│
         │  违约金比例/税率   │  写入     │  → 检索法规/行业  │
         │  保证金/付款比例   │  state    │    标准/案例     │
         └────────┬───────────┘          └────────┬─────────┘
                  ↓                               ↓ citations
         ┌─── AI 审核节点（三路并行）───┐
         │ ① 条款级风险扫描            │
         │ ② 数值逻辑校验              │
         │ ③ 合规检查（引用检索结果）   │
         └────────┬───────────────────┘
                  ↓ contract_risk_items
         ┌─── 风险卡渲染 ───┐
         │ 每条风险一条卡片   │
         │ 严重级别:          │
         │ critical/high/    │
         │ medium/low        │
         │ 三态交互:          │
         │ 采纳/不采纳/修改   │
         └──────────────────┘
