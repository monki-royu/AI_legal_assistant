一、前期调研与整体架构设计

1. 行业需求调研

研读合规政策、观看行业访谈，锁定合同审核、合规审查为核心刚需 , 梳理通用大模型在法律场景各类业务痛点，完成需求拆解与初步业务方案设计。

2. 多智能体技术选型

横向对比 OpenAI Agent、原生 LangChain、A2A、LangGraph 等编排方案，选定 可控性更高的 LangGraph 作为调度核心，依托原生状态机、并行 Send、人工 interrupt、状态持久化能力，适配 “自动初审 - 律师复核 - 强制签章” 法律闭环流程。

3. 底层数据底座搭建

基于 MinerU 搭建通用多模态解析流水线，统一 PDF / 扫描件 / Word 解析逻辑，自动提取文本、表格、印章并绑定页面 bbox 坐标，输出标准 JSON，实现一次解析、五大智能体共享，削减重复 OCR 算力消耗。
搭建双知识库体系：Neo4j 法律知识图谱完成法条、判例、行业规范实体与关系抽取；Milvus 向量库搭载 bge-m3 嵌入模型，配置 IVF/HNSW 双索引适配不同量级知识库，自研抽取流水线完成多源法律文档结构化入库。
二、五大可复用业务智能体开发（LangGraph 状态机编排）

1.通用检索智能体（全模块共享降本）

作为全系统共享检索底座，既支持独立接收关键词、条款、合同检索需求，又同步供所有 Agent 复用；
设计并迭代检索智能体，采用横向按需挂载多源知识库 + 纵向逐级降级双重容错策略：横向根据业务类型动态挂载行业专属数据源, 按数据源定制差异化检索策略；纵向按「高阶实体感知语义检索→本地规则全量扫描→LLM 兜底」逐级降级，保障召回准确率与系统鲁棒性
搭建三层并行检索体系：基础法律法规与案例强制检索、行业动态增强检索、关键词条款深度检索，内置数据源去重逻辑；
融合知识图谱查询、精确匹配、BM25 稀疏检索、向量召回，使用 RRF 互惠排序融合多路结果归一重排
硬编码 4 套法律效力冲突消解规则，设置 0.85 检索质量门禁，达标则跳过付费北大法宝 MCP 接口，输出可溯源原始法律原文证据，不生成主观分析结论,最多支持 3 轮自动重试，失败触发人工介入，大幅降低 API 调用成本。
2. 合同审核智能体（调用检索、合规审查智能体）

支持全自动 AI 审核、用户自定义规则双分支流程；
复用文档解析结果完成合同分类、条款切分；
搭建双层审核引擎：确定性数值校验基于 Python Decimal 高精度运算实现 7 条法定规则校验（违约金、定金、逾期利率阈值等），审核与审查数值校验规则双向引用，打通商业与合规双维度；LLM 调用公共检索智能体，从主体资格、合法性、商业对等性等 5 个维度识别风险。
融合多源证据划分风险等级，自动区分甲乙双方立场生成差异化修改建议；
依据风险分数三段式路由：低风险自动输出报告、中风险触发人工复核断点、高风险强制律师签章交付；
产出风险位置高亮的PDF、修订合同、全流程审计日志完整交付物。
3. 合规审查智能体

对标 ISO37301 合规体系，分为通用基础筛查、高风险场景深度审查；
数值型数据校验与合同审核智能体双向规则联动，合规结论优先级高于商业建议；
全流程记录风险与审批记录，满足企业审计要求。
4. 法律问答智能体

搭建 Neo4j 图谱 + 向量双路问答链路;
对用户问题进行实体抽取、Cypher 语句生成校验，图谱查询失败自动降级 RAG 兜底，覆盖法条、判例、企业内部制度多类咨询场景。
 5. 普法小红书智能体

标准化流程：主题输入→意图校验→文案配图生成→合规质检→自动重试→输出 Markdown 发布文档，实现律所普法内容批量自动化产出。
三、核心技术创新与落地优化

1. 底层能力全局复用：文档解析、检索引擎单例全局共享，消除重复算力与付费接口消耗，API 调用成本降低 60%；

2. 幻觉根治方案：金额、比例、期限类校验全部采用确定性 Python 代码，合同风险识别准确率稳定 95% 以上；

3. 精细化成本控制：基于检索质量动态开关付费 API，搭配重试限流，适配中小客户私有化预算；

4. 无代码规则体系：全部风控、行业规范配置在 YAML，法务无需开发即可迭代规则；

5. 全链路可观测：每个 LangGraph 节点留存输入输出、检索来源、风险坐标，支持完整流程复盘追溯；

6. 合规流程强制约束：高风险文书设置人工签章中断节点，贴合《律师法》要求，规避 AI 执业法律风险；

7. AIcoding研发提效：熟练使用各类 AI 辅助开发工具，可甄别、修改、验证 AI 生成代码，沉淀 AI 驱动高效研发流程。

四、量化技术 & 业务指标

技术指标
1. 共实现 5 套独立业务智能体，通过复用精简至 30 节点 ；内置 7 条常用数值校验规则、4 套冲突消解规则，8 大类检索数据源；

2. 甲乙合同立场识别准确率 94%，用户采纳 AI 风险建议　　比例 78%，复杂合同人工介入率　　仅 4%；

3.面向政府便民、小微律所、集团法务、个人用户提供不同部署交付方案。
