📌 【完整流水线】
  L2意图识别 → L5a文案生成 → L5b图片生成 → L5c图文检查
  ├─ ✅通过 → L5d自动发布 → L5eMarkdown存档 → END
  └─ ❌不通过 → END(不发布)

📌 【设计模式: 前置过滤(Filter-Before-Route)】
  所有用户请求 → 先判断是否小红书意图
  ├─ 是 → 走独立内容生产流水线(完全隔离)
  └─ 否 → 走主意图路由(合同/合规/检索/问答等)

📌 【降级策略】
  图片生成失败 → 无图发布(小红书支持纯文字)
  Playwright发布失败 → 不影响其他链路
  Cookies过期 → 提示用户扫码(≤180秒)
