│   ║     ...                                                        ║            │
│   ║                                                               ║            │
│   ║  ② 若已有完整case_summary → 跳过LLM(复用已分析结果)           ║            │

│   ║  ③ 构造LLM Prompt(含JSON Schema约束)                          ║            │
│   ║     prompt = f\"\"\"                                               ║            │
│   ║     请从以下用户输入中结构化抽取案情要素:                       ║            │
│   ║     用户输入: {user_input or input}                             ║            │

│   ║       }},                                                        ║            │
│   ║       \"facts\": [\"事实1\", \"事实2\"],                               ║            │
│   ║       \"claims\": [\"请求1\", \"请求2\"],                             ║            │
│   ║       \"evidence\": [\"证据1\", \"证据2\"]                            ║            │
│   ║     }}                                                           ║            │
│   ║                                                                 ║            │
│   ║     注意: 如果信息不足，请将need_clarify设为true                   ║            │
│   ║     并给出clarify_question追问用户                                ║            │
│   ║     \"\"\"                                                         ║            │
│   ║                                                               ║            │
│   ║  ④ JSON解析(含```json代码块剥离)                                ║            │
│   ║     支持多种格式: 纯JSON / ```json...``` / ```...```            ║            │

│   ╚═══════════════════════════════════════════════════════════════╝            │

│ [2/7] doc_template_match_node (模板匹配)                                     │
│ 【输入】state[\"case_summary\"] — 结构化后的案情                                 │
│ 【功能】根据案情的case_type/parties/facts等特征，匹配最合适的法律文书模板        │
│ 【10种预设模板】                                                               │
│                                                                               │
│   ╔═══════════════════════════════════════════════════════════════╗            │
│   ║  📋 10种法律文书模板库                                      ║            │
│   ║                                                              ║            │
│   ║  ① 民事起诉状  → ⭐最常用                                  ║            │
│   ║     适用: 借贷/买卖/租赁/侵权等民事纠纷                     ║            │
│   ║                                                              ║            │
│   ║  ② 民事答辩状  → 被告方使用                                ║            │
│   ║     适用: 收到起诉状后的答辩                                 ║            │
│   ║                                                              ║            │
│   ║  ③ 上诉状      → 二审程序                                  ║            │
│   ║     适用: 不服一审判决                                      ║            │
│   ║                                                              ║            │
│   ║  ④ 执行申请书  → 强制执行                                  ║            │
│   ║     适用: 判决生效后对方不履行                              ║            │
│   ║                                                              ║            │
│   ║  ⑤ 保全申请书  → 财产保全                                  ║            │
│   ║     适用: 防止对方转移财产                                  ║            │
│   ║                                                              ║            │
│   ║  ⑥ 劳动仲裁申请书 → 劳动争议                               ║            │
│   ║     适用: 劳动纠纷(必经仲裁前置)                            ║            │
│   ║                                                              ║            │
│   ║  ⑦ 行政复议申请书 → 行政争议                               ║            │
│   ║     适用: 对行政行为不服                                    ║            │
│   ║                                                              ║            │
│   ║  ⑧ 合同审查意见书 → ⭐法律顾问常用                         ║            │
│   ║     适用: 企业合同审核场景                                  ║            │
│   ║                                                              ║            │
│   ║  ⑨ 法律意见书  → 专项法律咨询                              ║            │
│   ║     适用: 投资并购/上市/合规等                              ║            │
│   ║                                                              ║            │
│   ║  ⑩ 律师函      → 催告/警告                                 ║            │
│   ║     适用: 催款/侵权警告/合同解除通知                        ║            │
│   ╚═══════════════════════════════════════════════════════════════╝            │
│                                                                               │
│ 【匹配逻辑】                                                                   │
│   基于case_summary中的字段做规则匹配:                                          │
│   - 合同纠纷 + 企业用户 → 合同审查意见书(⑧)                                    │
│   - 劳动纠纷 → 劳动仲裁申请书(⑥)                                               │
│   - 借贷纠纷 + 自然人 → 民事起诉状(①)                                          │
│   - 行政纠纷 → 行政复议申请书(⑦)                                               │
│   - ...(规则链)                                                                │

│   state[\"template_confidence\"] = 0.95 — 匹配置信度                            │
