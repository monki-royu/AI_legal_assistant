📌 【降级策略总览】
   Neo4j不可用 → matched_entities=[] → 跳过Cypher环节 → LLM直接回答(RAG补充)
   Cypher生成失败 → 重试≤3次
   Cypher校验失败≥3次 → 基于实体直接回答(降级)
   执行异常 → LLM直接回答

📌 【重试环机制】
   cypher_retry_count ∈ {0,1,2,3}
   0 → 初始,校验失败后+1 → 1 → 回退重新生成 → 校验失败+1 → 2 → 回退 → ... → 3 → 强制降级
