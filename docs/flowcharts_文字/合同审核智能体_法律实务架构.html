│ ════════════════════════════════════════════════  ││
│                                                  ││
│ 规则1：合规critical → 直接否决签约               ││
│   compliance_risk_items 中有任何 critical 级别    ││
│   → can_sign = "no" → 无论合同审核意见如何        ││
│     最终报告标注"❌ 不得签约"                     ││
│                                                  ││
│ 规则2：合规high → 强制整改                       ││
│   compliance_risk_items 中有 high 级别            ││
│   → can_sign = "conditional"                     ││
│   → 即使合同审核说"可接受"也必须改               ││
│                                                  ││
│ 规则3：同一问题双重发现 → 以合规为准             ││
│   合同审核和合规审查都发现了同一问题              ││
│   → 取合规的严重等级                             ││
│   → 在报告中标注来源                             ││
│                                                  ││
│ 规则4：合规通过 + 合同有风险 → 保留合同风险      ││
│   合规没发现问题，但合同审核发现了商业风险        ││
│   → 保留 contract_risk_items                     ││
│   → 标注为"商业风险（可谈判）"                    ││
│                                                  ││
│ 规则5：结论冲突 → 合规结论优先                   ││
│   合同审核说"该条款可接受"                        ││
│   合规审查说"该条款违法"                          ││
│   → 以合规结论为准                               ││
